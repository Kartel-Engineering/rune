- **Backdrop effects draw on a WebGL 2 canvas.** `El::backdrop_lens` (`Lens::prism()` included, frosted or clear) and `El::backdrop_blur` drew only their element's fill there, because wgpu offers a WebGL 2 canvas only as a render target, which the renderer can't copy what is under an effect from. A frame with a backdrop effect now draws into a texture the renderer keeps, which can be copied, and one more pass puts it on the canvas; a frame with none draws straight into the canvas as before. `Cx::backdrop_copies()` is now true on a WebGL 2 canvas, so a view that thins its fill on it (`rune_kit::glass_draws`) does there too. A frame a compositor draws on a WebGL 2 canvas still draws its effects' fill. WebGPU canvases and native windows are unchanged.
