- **Web: on WebGL 2, colours are no longer sRGB-encoded two times.** The web shell kept the surface's default format, which on WebGL 2 is an sRGB one, while the runtime still encoded every colour for a non-sRGB target, so `#202020` drew as `#636363` unless the app called `srgb_blend(false)`. The shell now picks the surface format the runtime's blend mode asks for when the surface offers it, and when it does not, it tells the runtime which encoding it got. An app gets the colour it wrote with no `srgb_blend` call.
