- **`Cx::on_gpu`: whether a window's frames draw on a GPU device.** False while a page draws on
  the CPU renderer before WebGPU takes over (or for good without it), while a Windows window
  draws its first frames on the CPU, in headless runs, and again after a device is lost; true
  from the first frame on a device. The view re-runs when it changes, so an app can hold back an
  effect the CPU painter draws slowly, such as a backdrop blur. `Runtime::set_on_gpu` sets it
  for a test. `on_gpu`'s `GpuEvent` hook still reports only native devices.
