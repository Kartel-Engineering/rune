- **Web: a browser that has `navigator.gpu` but no WebGPU adapter now falls back to WebGL 2.** The web shell made the canvas's WebGPU surface before it asked for an adapter, and a canvas that has a WebGPU context refuses `getContext('webgl2')`, so the fallback found no canvas and the app showed "WebGL2 ... canvas already in use". WebGPU now gets its adapter and device first and makes its surface after; only the WebGL 2 path makes its surface first.
